# ЛР9 — тест-план и тест-дизайн

## 1. Объект и уровни тестирования

Объект: PCHelper — веб-витрина, мобильное PWA, REST API и MCP-сервер.

| Уровень | Что тестируем | Инструмент |
|---|---|---|
| Unit | Бизнес-логика каталога, корзины, заказов | `node:test`, 35 тестов |
| API | Коды ответов, валидация, фильтры, токены | Playwright `request`, 11 тестов |
| UI E2E | Критические пользовательские сценарии | Playwright + POM, 31 тест |
| Доступность | Контраст, focus, aria, Lighthouse | Lighthouse, 100/100/100 |

Визуальная регрессия главной страницы реализована; кроссбраузерность и нагрузочный smoke вынесены в развитие.

## 2. Окружение и данные

- Backend: `http://127.0.0.1:3001/api/v1`
- Frontend: `http://127.0.0.1:5173`
- Браузер: Chrome (channel `chrome`)
- Тестовый пользователь: `demo@pchelper.by` / `demo1234`
- Переменные: `BASE_URL`, `API_URL`

Тесты изолированы: каждый тест создаёт новый browser context.

## 6. Использование ИИ

LLM использовался для генерации boilerplate Page Objects и начальных тестов. Каждый фрагмент проверен вручную: селекторы заменены на семантические (`getByRole`, `getByLabel`), assertions вынесены в тесты, фиксированные `sleep` не используются.
