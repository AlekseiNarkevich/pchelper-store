ИИ-подбор через MCP

Агент может собрать ПК по бюджету, проверить совместимость и оформить заказ через MCP-сервер PCHelper.

  1. Запустите MCP-сервер в режиме HTTP на порту 8080.
  2. Подключите Claude Desktop, Cursor или MCP Inspector к http://127.0.0.1:8080/mcp.
  3. Напишите агенту: «Собери игровой ПК до 4000 BYN».
python server.py --http --port 8080
npx @modelcontextprotocol/inspector
PCHelper — учебный проект, 2026. Демонстрационные данные; заказы не отправляются на сервер.
