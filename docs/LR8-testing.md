## Источник данных

Веб и мобильное приложение получают данные через REST API `/api/v1`.
При наличии `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` backend читает
реальный Supabase: категории — 8, товары — 96, готовые сборки — 7.
В CI без ключей используется фикстура, поэтому тесты герметичны.

MCP-сервер при запуске с `--sync-supabase` подтягивает каталог из Supabase
в локальную SQLite-копию; проверено: 96 товаров, 7 сборок.

## Supabase persistence

Миграция `db/09_supabase_commerce.sql` выполнена с включённым RLS. Сквозной
прогон через API:

- логин демо-пользователя — OK;
- добавление `cpu:1` quantity 2 → строка в `Корзина_Позиции`;
- оформление заказа → запись в `Заказы` и `Заказ_Позиции`;
- корзина после заказа пуста и в БД, и в API.

Backend использует `SERVICE_ROLE_KEY` и обходит RLS, поэтому дополнительные политики не требуются.
